| 1 | 0 (instant) | Deliver free resources | Build trust |
| 2 | 3 | Share productivity insight | First affiliate click |
| 3 | 7 | Social proof + soft pitch | Seed the upsell |
| 4 | 14 | Full Pro Bundle offer | Drive conversion |

## Setup in MailerLite

1. Create a new Automation
2. Trigger: Subscriber joins group "Inkfluence AI Subscribers"
3. Add 4 emails with delays between them
4. Set each email's content using the copy below

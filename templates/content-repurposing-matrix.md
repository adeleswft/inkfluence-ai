# Content Repurposing Matrix

## How to Use This Template

1. Start with ONE piece of long-form content (blog post, video transcript, podcast episode, or webinar)
2. Work through each platform below using the corresponding AI prompt
3. Schedule your content across the week using the calendar at the bottom
4. Track what performs best and double down on those platforms

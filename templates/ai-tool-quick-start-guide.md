## How to Set Up Your Stack (30 Minutes)

### Step 1: Create Your Accounts (5 minutes)

1. Sign up for ChatGPT Plus at chat.openai.com
2. Sign up for Notion at notion.so
3. Sign up for Make at make.com

### Step 2: Set Up Your Notion Workspace (10 minutes)

Create these 4 pages in Notion:

**Page 1: Client Tracker**
| Column | Type |
|--------|------|
| Client Name | Text |
| Project Type | Select (Writing, Design, Strategy, Other) |
| Status | Select (Lead, Active, Completed, Archived) |
| Start Date | Date |
| End Date | Date |
| Revenue | Number |
| Notes | Text |

**Page 2: Content Calendar**
| Column | Type |
|--------|------|
| Date | Date |
| Platform | Select (Twitter, LinkedIn, Instagram, Email, Blog) |
| Content Type | Select (Thread, Post, Carousel, Newsletter, Article) |
| Topic | Text |
| Status | Select (Draft, Scheduled, Published) |
| Performance | Text |

**Page 3: Prompt Library**
Create a page for each type of prompt you use regularly:
- Client emails
- Content creation
- Proposals
- Reports
- Social media

Paste your best prompts into each page. This becomes your personal prompt vault.

**Page 4: Tool Stack**
List every tool you use, its purpose, login URL, and monthly cost. This helps you track subscriptions and avoid tool bloat.

### Step 3: Connect Your Tools with Make (10 minutes)

Start with this simple automation:

**Automation: New Client = Auto-Welcome Email**

1. In Make, create a new scenario
2. Trigger: Notion — Watch Database Items (your Client Tracker)
3. Filter: When Status changes to "Active"
4. Action: Gmail — Send Email
5. Use this email template:

```
Subject: Welcome to [YOUR BUSINESS] — Let's Get Started

Hi [CLIENT NAME],

Welcome! I'm excited to work with you on [PROJECT TYPE].

Here's what happens next:
1. I'll send you a brief questionnaire (2 minutes)
2. We'll schedule a kickoff call
3. I'll share a project timeline within 48 hours

If you have any questions in the meantime, just reply to this email.

Best,
[YOUR NAME]
```

6. Turn on the scenario
7. Test by adding a test client in Notion

### Step 4: Start Using AI for Daily Tasks (5 minutes)

Try these 3 prompts today:

**Prompt 1: Client Email**
```
Write a professional email to a new client who just signed up for [SERVICE].
Include: thank you, what happens next, timeline, and my contact info.
Under 150 words. Friendly but professional tone.
```

**Prompt 2: Status Update**
```
Write a brief project status update. Completed this week: [LIST].
Upcoming next week: [LIST]. Any blockers: [LIST].
Under 100 words. Confident and proactive tone.
```

**Prompt 3: Social Media Post**
```
Write a LinkedIn post about [TOPIC].
Start with a hook, share a practical tip, end with a question.
Under 1,300 characters. Professional but conversational.
```

## When to Add More Tools

Do NOT add tools because they exist. Add them only when:

| Need | Tool to Add |
|------|------------|
| You need to design graphics | Canva Pro |
| You record meetings | Fireflies.ai or Otter.ai |
| You create long-form content | Jasper AI or Writesonic |
| You need SEO optimization | Surfer SEO or Semrush |
| You do video editing | Descript |
| You need AI image generation | Midjourney or DALL-E |
| You manage email marketing | MailerLite |
